## ADR Приведення ci-shared до канонічного n-cursor стандарту (n-fix)

**Контекст:** Репозиторій `ci-shared` використовує набір правил `@nitra/cursor` (bun, changelog, ga, image-compress, js-lint, js-run, npm-module, text), однак `npx @nitra/cursor check` виявив ~10+ відхилень від канону: відсутній `bunfig.toml`, застарілий `.oxlintrc.json`, невідповідний набір GitHub Actions workflows, missing `hk.pkl`, `npm/types/index.d.ts`, `.markdownlint-cli2.jsonc`, `.jscpd.json`, `.v8rignore`, а також вади shellcheck у workflow.

**Рішення/Процедура/Факт:**
Запущено `/n-fix` (skill `n-fix`), який автоматично:

1. Створив `bunfig.toml` (`[install] linker = "hoisted"`).
2. Замінив `.oxlintrc.json` на канонічний з `node_modules/@nitra/cursor/scripts/utils/oxlint-canonical.json`.
3. Переписав `clean-merged-branch.yml` та додав `clean-ga-workflows.yml`, `lint-ga.yml`, `git-ai.yml`, `.github/zizmor.yml`.
4. Додав `lint-js.yml`, `lint-text.yml` workflows; `.jscpd.json`, `.v8rignore`, `.markdownlint-cli2.jsonc`.
5. Створив `npm/jsconfig.json`, `npm/types/index.d.ts`, `hk.pkl` (pre-commit / tsc).
6. Додав scripts `lint-ga`, `lint-js`, `lint-text` у кореневий `package.json`.
7. Виправив `eslint.config.js` (`ignores: ['**/auto-imports.d.ts']`), `.cspell.json`, `.oxfmtrc.json` (`ignorePatterns`), `.vscode/extensions.json` і `.vscode/settings.json` (formatOnSave + per-language formatters).
8. Додав `.claude/hooks/capture-decisions.log` до `.gitignore`.
9. Виправив shellcheck SC2086 у `git-ai.yml` (лапки навколо `$GITHUB_PATH`).
10. Додав placeholder `export {}` до `npm/src/schema.js` (oxlint `no-empty-file`).
    Підсумок: `npx @nitra/cursor check` — 9/9 правил ✅; `lint-ga`, `lint-js`, `lint-text` — код виходу 0.

**Обґрунтування:** Централізований стандарт `@nitra/cursor` гарантує однорідність CI/CD, конфігурацій linter і toolchain між усіма репозиторіями Nitra. Виконання `n-fix` автоматизує приведення до цього стандарту без ручних розбіжностей.

**Розглянуті альтернативи:** Не обговорювалися; завдання — механічне приведення до існуючого канону.
