## ADR Автоматичне виправлення проєкту ci-docs під канонічні правила @nitra/cursor

**Контекст:** Репозиторій `nitra/ci-docs` не відповідав низці канонічних правил `@nitra/cursor` (bun, ga, js-lint, js-run, npm-module, text): були відсутні обов'язкові конфіги та workflow, .oxlintrc.json відрізнявся від канону, lint-скрипти не покривали повний ланцюжок, knip сигналізував про false positive–попередження.

**Рішення/Процедура/Факт:**
Запущено `/n-fix` (скіл автовиправлення), після чого застосовано `/n-lint` для усунення порушень линтингу. Конкретні зміни:

- **bun:** створено `bunfig.toml` з `linker = "hoisted"`.
- **ga:** переписано `clean-merged-branch.yml`; створено `clean-ga-workflows.yml`, `lint-ga.yml`, `git-ai.yml`, `.github/zizmor.yml`; додано скрипт `lint-ga` і formatter `[github-actions-workflow]` у `.vscode/settings.json`; виправлено `$GITHUB_PATH` (shellcheck SC2086).
- **js-lint:** замінено `.oxlintrc.json` на канонічний з `@nitra/cursor`; оновлено `eslint.config.js` (додано `ignores: ['**/auto-imports.d.ts']`); створено `lint-js.yml`, `.jscpd.json`; додано `engines.bun` у `npm/package.json`.
- **js-run:** створено `npm/jsconfig.json`; додано крок `depcheck` у `npm-publish.yml`.
- **npm-module:** створено `npm/types/index.d.ts` та `hk.pkl` (pre-commit + tsc).
- **text:** створено `.v8rignore`, `.markdownlint-cli2.jsonc`; оновлено `.vscode/extensions.json` і `.vscode/settings.json` (formatOnSave + per-language formatters); прописано `lint-text` з `run-shellcheck-text.mjs`/`run-v8r.mjs`; оновлено `.oxfmtrc.json` (ignorePatterns); додано слова в `.cspell.json`.
- **lint (після lint-js):** прибрано `process.exit()` з `npm/src/cli.mjs` (замінено на `process.exitCode`); виправлено JSDoc у `npm/test/sync-schema/main.test.mjs`; прибрано невикористаний імпорт у `npm/test/commit-push/main.test.mjs`; виправлено `.map(parseHeader)` → `.map(h => parseHeader(h))`.
- **gitignore:** додано `.claude/hooks/capture-decisions.log`.
- **npm publish:** додано `"publishConfig": { "access": "public" }` у `npm/package.json` для публікації скоупованого пакета `@nitra/ci-docs` як публічного.

**Обґрунтування:** Правила `@nitra/cursor` — корпоративний стандарт монорепо (bun, GA, text, lint). `npx @nitra/cursor check` вирішує, чи проєкт відповідає стандарту; CI та PR-перевірки спираються на ці самі скрипти. Без `publishConfig.access: "public"` npm за замовчуванням відмовляє у публікації скоупованих пакетів для неплатних org-акаунтів.

**Розглянуті альтернативи:** Щодо `bin`-бінарника `cli.mjs` у `npm/package.json` — npm 11 сигналізував про невалідну назву; альтернатива `npm pkg fix` не розглядалася детально, вирішено зберегти поточну структуру без змін до bin. Щодо false positive попереджень `knip` (unused files, deps, binaries) — прийнято рішення **не виправляти**, бо це наслідок архітектурного вибору (CLI-інструменти через `bunx`/`npx` без deps, тест-файли через `bun test`, конфіги для зовнішніх CLI).
