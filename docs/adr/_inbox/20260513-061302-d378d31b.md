## ADR Приведення `@nitra/ci-docs` до канону `@nitra/cursor` (n-fix + n-lint, 2026-05-13)

**Контекст:** Репозиторій `@nitra/ci-docs` поступово накопичив відхилення від канонічних правил `@nitra/cursor` — відсутній `bunfig.toml`, не повний набір GitHub Actions workflows, старий `.oxlintrc.json`, відсутня типізація через `tsc`, відсутній `knip.json`, порушення eslint/oxlint у тест-файлах. Результат `npx @nitra/cursor check` показував 9+ критичних відхилень; `bun run lint` виходив з ненульовим кодом.

**Рішення/Процедура/Факт:**
- **bun:** створено `bunfig.toml` з `[install] linker = "hoisted"`.
- **ga:** переписано `clean-merged-branch.yml`; створено `clean-ga-workflows.yml`, `lint-ga.yml`, `git-ai.yml`, `.github/zizmor.yml`; у `.vscode/settings.json` — форматер `[github-actions-workflow]`.
- **js-lint:** `.oxlintrc.json` замінено на канонічний з `@nitra/cursor/scripts/utils/oxlint-canonical.json` (додані плагіни `vue`, `@e18e/eslint-plugin`); `eslint.config.js` — додано `ignores: ['**/auto-imports.d.ts']`; створено `lint-js.yml`, `.jscpd.json`, `knip.json` (canonical ignoreBinaries/ignoreDependencies/entry).
- **js-run:** `npm/jsconfig.json` (NodeNext); `process.env.GITHUB_OUTPUT` → `env` з `node:process`; `process.exit()` замінено на `process.exitCode` + ранній return у `npm/src/cli.mjs`; `.map(parseHeader)` → `.map(h => parseHeader(h))` (unicorn/no-array-callback-reference).
- **npm-module (Variant B):** джерела під `npm/src/` — виключно `.mjs`, `.js`-файлів немає → Variant A (inline tsc-флаги) не застосовний. - **text:** `.v8rignore`, `.markdownlint-cli2.jsonc` (з `MD024: { siblings_only: true }` для Keep-a-Changelog-сумісності); `.vscode/extensions.json` — markdownlint, shellcheck; `lint-text`-скрипт через `run-shellcheck-text.mjs` + `run-v8r.mjs`; `lint-text.yml`; `.oxfmtrc.json` — `ignorePatterns`.
